Welcome to WebServ

A lightweight HTTP/1.1 compliant web server built from scratch in C++. This project demonstrates core networking concepts including socket programming, multiplexing with epoll, and HTTP protocol handling.

Server Features

WebServ supports GET, POST, and DELETE methods, CGI script execution, file uploads, custom error pages, and multiple virtual host configurations. The server efficiently handles concurrent connections using the epoll event-driven architecture.

Getting Started

Navigate through the tabs above to explore different features. Try the CGI Demo to execute server-side scripts, or upload files through the File Upload page. The Gallery showcases static content serving capabilities.
